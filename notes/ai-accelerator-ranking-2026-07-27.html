一、结论先行:总排名

打分方法完全透明:每个维度取「该卡指标 ÷ H20 同指标」的比值 r,记 s = 1 + log2(r)(上限 8,下限 0),再按权重加权求和,归一化到 H20 = 100。 用 log2 而不是线性比值,是因为硬件指标跨了两个数量级(FP4 峰值最大差 136 倍),线性加权会让单一维度吃掉整张表。每翻一倍加 1 分,这个尺度更接近工程直觉。 权重:显存带宽 15、FP8 级算力 15、显存容量 10、FP4 级算力 10、能效 10、软件栈+MFU 10、数值格式 8、Scale-up 带宽 8、超节点域 7、片上 SRAM 7。

四、数值格式的原生支持

「支持 FP8」这句话在 2026 年已经不够用了。真正影响工程的是三件事:(1) Tensor Core / MME 是否原生做这个格式的矩阵乘(而不是软件模拟或先反量化再算); (2) 缩放是 per-tensor 还是 micro-block(MX / NVFP4 / HiF8) —— 微缩放决定 FP4 能不能真的用在训练而不掉精度;(3) 有没有配套的量化算子库。 昇腾 950 系列一口气加了 FP8 / MXFP8 / MXFP4 / HiF8 / HiF4,是这代国产卡最实质的一步;而 910C 完全没有 FP8,只能靠 BF16 硬扛,这是它在本次排名里被 950DT 拉开的核心原因。

五、Scale-up 互联与超节点域规模

单卡指标已经不是 2026 年的主战场。真正决定能不能训万亿参数、能不能把 MoE 的 expert 全放进一个内存域的,是一个 scale-up 域里能塞多少张卡、卡间带宽多少。 这里出现了本次统计最戏剧的一组数字:华为昇腾用 8192 卡的 Atlas 950 SuperPoD 换取单卡劣势,Google 用 3D Torus + OCS 做到 9216 卡,而 NVIDIA/AMD 的机架域仍是 72 卡量级。

六、片上 SRAM / L2:FlashAttention 到底能开多大

这一项经常被表格忽略,但它直接决定 kernel 怎么写。要分两层看:

  1. 每个计算核可编程的近存(shared memory / LDS / VMEM / SBUF) —— 它才是 FlashAttention 分块大小的硬上限。GPU 上 Hopper/Blackwell 每 SM 最多 228 KB shared memory,一个 BF16 的 128×128 tile 是 32 KB,所以 Q/K/V + 累加器要在 228 KB 里挤;Blackwell 又额外给了 256 KB TMEM 专供 Tensor Core。AMD CDNA4 每 CU 160 KB LDS。
  2. 全局末级缓存(L2 / Infinity Cache) —— 它决定 KV cache、权重分块、all-reduce 中间量有多少能不回 HBM。B200/B300 是 126 MB L2,MI355X 是 256 MB Infinity Cache,MI455X 是 2×96 MB L2。

而 TPU / Trainium 走的是完全不同的路线:用大块可编程 scratchpad 替代缓存。TPU 8i 有 384 MB 片上 SRAM(比 Ironwood 的 128 MB 多 3 倍),Google 的说法是「把模型的活跃工作集整个留在片上」;Trainium3 的 SBUF 是 256 MiB,并且是编译器显式管理的。 这解释了为什么这两家在长上下文 decode 上能拿到相对高的效率 —— 它们不是靠更大的 HBM 带宽,而是靠让 attention 的中间量根本不落 HBM。

七、TDP 与是否强制液冷

2026 年的分水岭很清楚:1 kW 以上的卡已经没有风冷 SKU 了。R200 官方口径是 1800 W Max-Q / 2300 W Max-P,100% 液冷、45 °C 进水、机架走 800 V DC; AMD Helios 整机 225–245 kW,用 50 V 液冷母排 + 每 GPU/每 HBM4 堆独立冷板;而 Intel 反其道行之 —— Crescent Island 用 LPDDR5X 把整卡压到 350 W 风冷 PCIe,主打「进得了存量风冷机房」。 对国产卡来说,昇腾 950PR 的 600 W(是 H20 的 1.5 倍)配 112 GB / 1.4 TB/s,已经说明工艺代际差要用功耗来补。

十、选型结论

  1. 前沿训练(万亿参数 MoE):R200 与 MI455X 是唯一两个选项,决策点不是 PFLOPS 而是「你有没有 250 kW 机架 + 45 °C 冷液」和「你的栈是 CUDA 还是 ROCm」。若模型是超大 MoE,把预算优先给 scale-up 域(NVL144 / Helios 72 / UALoE),而不是给单卡峰值。
  2. 长上下文推理:走 PD 分离。prefill 用高山脊点、便宜显存的卡(Rubin CPX 是原生答案,昇腾 950PR 是同思路的国产版),decode 用高带宽 + 大 SRAM 的卡(R200 / TPU 8i / 950DT)。用一种卡同时干两件事在 2026 年已经是浪费。
  3. 国产替代:昇腾 950DT 是这一代唯一在数值格式(FP8/MXFP4/HiF8)、带宽(4 TB/s)、超节点(8192 卡)三项上同时够格的国产卡;思元690 靠 196 GB 显存打大模型单卡部署;S5000 / C600 的优势是 vLLM/SGLang/Megatron 迁移几乎零成本。选型时务必要求实测 MFU 与端到端 tokens/s,而不是峰值 TFLOPS。
  4. 存量风冷机房:Crescent Island(350 W、160–480 GB LPDDR5X)和 Gaudi 3(900 W 风冷)是少数还能塞进老机房的选择,代价是带宽只有 HBM 卡的 1/5 到 1/15,只适合大显存、低并发的 agent 推理。
  5. 方法论警告:本文任何一个排名都不该单独用于采购。峰值算力的可信度 > 带宽 > SRAM > MFU;而对 TCO 的影响顺序恰好相反 —— MFU 和液冷改造费才是真正花钱的地方。
