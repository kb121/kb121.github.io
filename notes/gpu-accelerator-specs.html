读表前先看口径Read the fine print first

  • 稀疏和稠密不能混比。NVIDIA 规格页把稀疏值标 *,B300 datasheet 只给稀疏值并注明「稠密为所示值的 ½」;AMD 写「结构化稀疏」;Intel 白皮书只写峰值、不标稀疏或稠密。表里照抄原文的标注,没标的就是没标 —— 不同厂商的 PFLOPS 不能直接比大小。 Sparse and dense don't mix. NVIDIA's spec pages mark sparse values with *, and the B300 datasheet lists only sparse values with a note that dense is ½ of what's shown. AMD says "structured sparsity". Intel's whitepaper gives peak figures without saying either. The table copies each source's labelling; where none is given, none is shown. PFLOPS from different vendors are not directly comparable.
  • 单卡和整板 / 整机分开放。B200、R100、Groq 3 LPU 的一部分数字官方只给 HGX 基板、NVL72 整机或托盘值,这些都放在「其他官方指标」行,不除以卡数。 Per-chip and per-board / per-rack figures stay apart. For B200, R100 and the Groq 3 LPU some numbers are only published for the HGX board, the NVL72 rack or the tray. Those go in the "Other official figures" row and are never divided by the chip count.
  • 同一颗芯片可能拆成两列。B300 在 GB300 NVL72 与 HGX B300 里的官方规格不同(279 GB / 8 TB/s / 最高 1,400 W 对 270 GB / 7.7 TB/s / 最高 1,100 W),所以分两列;昇腾 950PR / 950DT 格子里的「/」是白皮书所说同一芯片衍生出的不同规格版本。 One chip can take two columns. B300's official specs differ between GB300 NVL72 and HGX B300 (279 GB / 8 TB/s / up to 1,400 W versus 270 GB / 7.7 TB/s / up to 1,100 W), so each gets its own column. In the Ascend 950PR / 950DT cells, "/" separates the variants the whitepaper says are derived from the same chip.
  • 一列引用多份文档时用 ①②③ 标出处,对应该列「来源」行的序号。两份官方文档互相矛盾时两个数并列、不取舍,例如 R100 的显存带宽、MI300X 的 Infinity Fabric 链路数。 ①②③ mark which source a value comes from when a column cites more than one document, matching the numbering in that column's Sources row. When two official documents disagree, both values are listed without picking one — R100's memory bandwidth and MI300X's Infinity Fabric link count, for example.
  • Groq 与 Cerebras 不走 HBM。它们的 150 TB/s 与 21 PB/s 是片上 SRAM 带宽,和其他卡的 HBM 显存带宽不是一个口径。 Groq and Cerebras don't use HBM. Their 150 TB/s and 21 PB/s are on-chip SRAM bandwidth, which is not the same quantity as the HBM bandwidth of the other cards.
