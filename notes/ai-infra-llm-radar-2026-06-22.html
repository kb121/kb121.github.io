AI Infra 与大模型雷达:当天 / 一周 / 一月 / 半年 / 一年热点与趋势

这是一份滚动雷达。统计口径是 2026-07-07 22:00 UTC 附近可查证的信息: GitHub 项目热度取 stars、release、push 时间与项目描述; 新闻/趋势取官方公告、项目 release、云厂商技术博客与行业报道。 结论很清楚:AI Infra 的竞争重心正从“模型参数更大”迁移到“推理系统是否能把昂贵算力持续喂满”。

一眼结论

  • 算力变成长期金融合约。 7 月 7 日报道显示 Anthropic 与 TeraWulf 签下约 19B 美元、20 年、401MW 数据中心租约,说明 AI Infra 从“租 GPU”升级成“锁电力、土地、冷却和网络”。
  • 推理成为主战场。 NVIDIA Vera CPU 官方博客把 CPU 放上 agentic inference critical path:工具调用、KV-cache 协调、sandbox/code execution 都会影响 GPU 利用率。
  • KV cache 从优化细节变成分布式系统。 vLLM v0.24、LMCache v0.5.1、SGLang HiCache、NVIDIA Rubin 的 Inference Context Memory 都在围绕 cache placement/transfer/offload/reuse 迭代。
  • Kubernetes 正在补 AI inference 的语义。 llm-d、Gateway API Inference Extension、KAITO ProductionStack、KServe 共同把“模型、请求状态、KV cache、GPU 拓扑”暴露给调度与路由。
  • agent stack 进入生产约束。 MCP servers 88K+ stars、LangGraph 36K+ stars、browser-use 103K+ stars、Vercel Eve 的 durable execution/microVM/credential layer,都说明 agent 不再只是 prompt demo。

技术趋势:历史、当下、未来

历史:为什么从“训练规模”转向“推理系统”?

早期 LLM 基础设施的中心问题是训练:数据并行、张量并行、ZeRO、checkpoint、模型分发。 但 2023 年以后,应用流量和开源模型让推理成为持续成本中心。vLLM 的 PagedAttention 把 KV cache 管理带进工程主线, llama.cpp/Ollama/Open WebUI 则证明本地推理不是玩具,而是开发者入口。

证据:截至本次统计,Ollama 约 175K stars、Open WebUI 约 144K、llama.cpp 约 119K; 生产推理侧 vLLM 约 85.6K stars, SGLang 约 30K stars。热度同时出现在“本地入口”和“生产引擎”,说明这不是单一云厂商趋势。

当下:四个瓶颈决定单位 token 成本

  1. 电力和机房:Anthropic 401MW 租约把容量锁定提前到 2027/2028,表明电力接入周期和大型租约会影响模型公司的增长曲线。
  2. 内存和 KV cache:Modular 对 MLSys 2026 的总结指出 KV cache 已成为主导子系统; LMCache/vLLM/SGLang/NVIDIA Inference Context Memory 都在解决 cache 跨层复用。
  3. MoE 通信:Google Cloud A4X + Dynamo 把 WideEP、DeepEP、P/D 解耦和全局 KV cache 管理放进 rack-scale 设计,因为 MoE 的约束已经从单卡算力转到 all-to-all、HBM 和拓扑。
  4. 控制面和治理:GitHub Models 退役、Otari 发布、Vercel Eve 的 sandbox/credentials/durable execution,说明 production LLM app 需要预算、failover、审计、隔离和恢复语义。

未来:我会押注的 6 条技术线

  1. KV cache 会成为“推理数据库”。会出现更明确的 cache schema、生命周期、权限、跨模型复用、热/冷分层和故障恢复。
  2. P/D/E 解耦会标准化。Prefill、Decode、Encode(多模态)会像 web 的 stateless/stateful 服务一样被拆分、独立伸缩和独立定价。
  3. Kubernetes 需要 inference-native API。普通 Service/Ingress 不懂 TTFT、ITL、KV locality、model warmup 和 GPU topology; llm-d/GWIE/KAITO/KServe 会继续补语义。
  4. 硬件异构会倒逼 portable kernels。NVIDIA、AMD、TPU、XPU、CPU/edge 同时存在,Mojo/Triton/CuteDSL/FlashInfer/MLX 等抽象会继续抢“可移植性能层”。
  5. agent runtime 会像应用服务器一样标准化。durable execution、sandbox、short-lived credentials、human approval、evals/trace 将成为生产 agent 的默认要求。
  6. 成本治理会前置到开发阶段。模型路由、budget、quota、prompt/cache policy、fallback 和审计不再是平台团队后补,而是应用架构的一部分。
